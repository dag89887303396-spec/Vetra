# VetraEstate — готовый статический сайт

## Как открыть
Откройте файл `index.html` в браузере.

## Как загрузить на Netlify
1. Зайдите на netlify.com
2. Выберите Add new site → Deploy manually
3. Перетащите всю папку `vetraestate_full_site` или ZIP-архив
4. Netlify выдаст ссылку на сайт
